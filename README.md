### Calculadora de Integrais Numéricas

Aplicação desenvolvida em **C# e Windows Forms** para realizar cálculos de integrais numéricas utilizando o **Método dos Trapézios Repetidos**.

O projeto foi desenvolvido como parte da graduação em Engenharia de Computação, envolvendo conceitos de programação, matemática computacional e manipulação de vetores e matrizes.

**Tecnologias:**

- C#
- .NET
- Windows Forms

---

### Pipeline de Dados em AWS

Projeto desenvolvido em ambiente profissional para processamento e consulta de dados utilizando serviços da AWS.

Foi implementado um pipeline utilizando **AWS Glue e Python**, com processamento direcionado à partição mais recente dos dados.

**Resultado obtido:**

- Redução superior a **90% no tempo e custo das consultas**

---

### Cloud & Infraestrutura

Experiência prática com serviços AWS e infraestrutura como código, envolvendo recursos como **Amazon S3, AWS Lambda e Terraform**.

Também foi realizada a utilização do **S3 Intelligent-Tiering**, buscando otimizar os custos relacionados ao armazenamento de dados.

**Resultado obtido:**

- Redução aproximada de **30% nos custos de armazenamento**
